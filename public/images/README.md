# Imágenes

Coloca el logo original en `logo.png`: se detecta automáticamente al iniciar o compilar. No se modifica ni se recorta. Si falta, se muestra el nombre en texto; ese texto no es un logo nuevo.

Añade fotografías y portada autorizadas aquí, y asigna sus rutas (por ejemplo `/images/retrato.jpg`) en `src/lib/content.ts`. Usa imágenes locales con textos alternativos descriptivos. No incluyas materiales sin autorización.
